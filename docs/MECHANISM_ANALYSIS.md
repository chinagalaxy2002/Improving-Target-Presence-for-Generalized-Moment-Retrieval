## 1. 审稿人视角的本质审视：传统参数假说的局限性

在分析 VTG 模块有效性时，研究者常倾向于展示微观特征变化（例如“注意力更加聚焦”、“特征余弦相似度提高”）。但在顶级同行评审中，单纯依赖此类指标极易遭遇审稿人的双重质疑：

1. **循环论证（Circular Reasoning）风险**：
   若模型在训练阶段引入了显式拉近时序重合度的损失项（如 $\mathcal{L}_{\text{bind}}$），测试阶段再去测“注意力在真实区间的重叠比例是否上升”，审稿人会认为这是优化器在既定目标下的自然收敛，**并不能证明原始任务本身存在必须引入新架构的深层物理病灶**。
2. **解释力脱节（Attention $\neq$ Explanation）风险**：
   正如 NLP 与多模态可解释性研究所揭示的，内部注意力的能量分布并不等同于模型决策的真实因果链。注意力集中完全可能是模型过拟合了某种全局视觉运动伪影（如进球后的镜头推近或特定球员的剧烈冲刺），而非真正理解了文本语义。

### 真正的任务本质病灶：视觉先验惯性与语义盲视 (Visual Inertia & Semantic Blindness)
传统的 Video Temporal Grounding (VTG) 模型几乎全部在“每个文本在视频中必然存在唯一对应片段”的封闭数据集上预训练。这种任务范式给各类 Transformer 解码器带来了一种隐蔽且顽固的**结构性惰性**：
- 解码器中的固定候选 Query 并不是通过“深度理解文本动作”来扫描视频，而是倾向于**锚定在视频本身的显著性先验（Visual Saliency Prior）上偷懒**；
- 无论给它输入什么文本指令，解码器往往都习惯性地吐出视频中最活跃、镜头运动最剧烈的时间片段；
- 这种对文本语义的严重解耦，直接导致了传统 VTG 模型在开集泛化与负样本拒识场景下的全面溃败。

## 2. 直击本质的实验设计与量化度量体系

为了让审稿人无可辩驳地信服，我们构建了一套基于**黑盒扰动因果干预**与**误差正交分解**的度量体系：

### 度量 1：错位文本扰动因果测试 (Mismatched Query Perturbation Test)
- **测试机制**：保持输入视频 $V$ 完全不变，分别输入其匹配的真实文本查询 $Q_{\text{normal}}$，以及从其他完全无关视频中随机采样的错位文本查询 $Q_{\text{mismatch}}$（例如将“球员头球破门”替换为“主裁判出示红牌”）。
- **核心指标 A：候选惯性重合度 (Proposal Inertia, $\text{PI}$)**
  $$\text{PI} = \text{IoU}\left(\hat{W}(V, Q_{\text{normal}}), \, \hat{W}(V, Q_{\text{mismatch}})\right) \times 100\%$$
  - **物理含义**：度量模型在文本语义被完全颠覆时，生成的时序候选窗口有多大程度发生“位置惯性重合”。若模型具有真实的文本理解能力，$\text{PI}$ 应显著下降；若模型靠视觉显著性瞎猜，$\text{PI}$ 将接近 100%。
- **核心指标 B：置信度下跌敏感度 (Confidence Drop, $\Delta\text{Conf}$)**
  $$\Delta\text{Conf} = \text{Score}(V, Q_{\text{normal}}) - \text{Score}(V, Q_{\text{mismatch}})$$
  - **物理含义**：面对完全不相干的错误文本时，模型能否主动、大幅度抑制其前景激活强度。

### 度量 2：误差正交分解体系 (Orthogonal MECE Decomposition)
在 Generalized Moment Retrieval 中，模型的全部检索赤字在数学上由两个互斥且完备的成分构成：
$$\text{Total Deficit} = \underbrace{(1.0 - \text{Oracle}_{G1})}_{\text{第一阶段：物理定位上限赤字 (Proposal Deficit)}} + \underbrace{(\text{Oracle}_{G1} - \text{G1-AUC})}_{\text{第二阶段：存在性门控赤字 (Presence Deficit / Orc-Gap)}}$$

```
总检索赤字 (100%)
 ├── 1. 物理定位上限赤字 (1.0 - Oracle)   <─── 【Stage 1: DQ-CGPv3 攻克目标】
 │      (即便存在性门控 100% 理想，模型所能达到的几何重合上限)
 └── 2. 存在性门控决策赤字 (Orc-Gap)      <─── 【Stage 2: GEQ 攻克目标】
        (因负样本虚警与正样本漏检造成的 G-mIoU 面积损失)
```

### 度量 3：真实时序物理边界误差
针对 544 条含动作真值的测试样本，度量预测窗口 $\hat{w} = [\hat{s}, \hat{e}]$ 与真值窗口 $w^* = [s^*, e^*]$ 的绝对几何物理量：
- **中心偏移绝对误差 (Center-Shift Error, CSE)**：$\mathbb{E}[|\hat{c} - c^*|]$（单位：秒）；
- **时长失真绝对误差 (Duration Distortion Error, DDE)**：$\mathbb{E}[|\hat{d} - d^*|]$（单位：秒）；
- **高重合紧致召回率 ($\text{Rec@IoU} \ge 0.5$ / $\text{Rec@IoU} \ge 0.7$)**：衡量切片边界是否真正紧致包裹动作。

## 4. DQ-CGPv3 的底层神经机制与架构实现

DQ-CGPv3 之所以能取得上述黑盒层面的物理改善，其架构设计严格对应了对 VTG 本质缺陷的手术级治理：

```
                    ┌────────────────────────┐
                    │ 静态查询语义 (Semantic)  │
                    └───────────┬────────────┘
                                │
[Decoder State (Candidate)] ────┼──► [双查询时序绑定 (Temporal Binding)]
                                │                  │
                                │                  ▼ 显式监督时序质心 (L_bind)
                                │          [动态时序上下文 (Context)]
                                │                  │
                                ├──► [路由网络 (RCG)] ◄┘
                                │          │
                                │          ▼ 熵正则化 (L_route)
                                │   [Prompt 基库软加权 (BPS)]
                                │          │
                                └──► [特征精炼融合 (FRF)]
                                           │
                                           ▼ 固定强度残差直通 (beta)
                                  [连续梯度路由更新 (CGP)] ──► 进入下一层 Decoder
```

### 1. 双查询联合寻址（打破语义盲视的物理抓手）
不再让 Query 作为一个无语义的几何槽位（Slot）去盲目检索，而是将**解码器第一层的动态候选状态**与**文本全局谓词语义**显式融合：
$$\mathbf{Q}_{\text{temp}} = \text{Proj}_{\text{cand}}(\text{LayerNorm}(\mathbf{H}_{\text{cand}})) + \text{Proj}_{\text{sem}}(\mathbf{S}_{\text{text}})$$
强制每一个候选带着具体动作意图去计算时序注意力权重 $\mathbf{A}_{\text{temporal}}$，这就是为什么在错位测试中候选重合度能够断崖式下降 44 个百分点的原因。

### 2. 连续梯度直通回路（Continuous Gradient Path, CGP）
精炼后的复合提示向量通过非优化强度的残差通路直通回传：
$$\mathbf{H}_{\text{adapted}} = \mathbf{H}_{\text{cand}} + \beta \cdot \text{LayerNorm}(\text{Proj}_{\text{res}}(\text{FRF}(\dots))) \quad (\beta=0.05)$$
该通路在 Transformer 两层解码器之间开辟了一条**直通底层视觉特征与 Prompt 知识库的高速公路**，彻底规避了深层 Softmax 注意力造成的梯度耗散与特征平滑。
